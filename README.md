# Фінальний проєкт: інфекційні захворювання (goit-rdb-fp)

Notebook із PostgreSQL: завантаження датасету, нормалізація до 3НФ,
аналітичні запити та власні SQL-функції.

## Датасет

Джерело — курсова копія файла `infectious_cases.csv` на
[Google Drive](https://drive.google.com/file/d/1dQf-uVXzYPYYGgXsG1y4Q1qDdhP2miZl/view).
Це Kaggle-датасет [Infectious statistics of the World](https://www.kaggle.com/datasets/brunopighi/infectious-diseases)
(автор Bruno Pighi). Дані первісно зібрані Our World in Data на основі
статистики ВООЗ і Світового банку: кількість випадків інфекційних захворювань
за країнами, регіонами та роками.

Розмір вибірки:

- файл `data/infectious_cases.csv`, 540 895 байт, SHA-256
  `226a0ff1916de44182d881b00d21cd59c1d58ae2ff6ec47d7a8042d7bc03f289`;
- 10 521 рядок даних, 12 колонок;
- 245 унікальних комбінацій `Entity` + `Code` (окремі країни, регіони та групи);
- роки 1920–2023, показники хвороб мають багато пропусків
  (наприклад, `Number_rabies` відсутній приблизно у 36% рядків).

## Як отримати файли

CSV уже в репозиторії — вистачить склонувати його й відкрити ноутбук.
Якщо файла немає, ноутбук сам його довантажить:

1. спочатку шукає `data/infectious_cases.csv` у папці проєкту;
2. потім `/content/infectious_cases.csv` (для Colab, куди файл можна
   закинути вручну);
3. наостанок завантажує курсову копію з Google Drive.

Після цього ноутбук звіряє SHA-256, щоб не працювати з іншою версією даних.

## Як запустити

Локально:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab goit-rdb-fp.ipynb
```

У Google Colab: відкрийте `goit-rdb-fp.ipynb`, виконайте Runtime →
Restart and run all. Ноутбук сам підніме PostgreSQL: для Python 3.9–3.12
через `pgserver`, для новіших версій — через системний PostgreSQL з apt.
Якщо `pgserver` не встановиться, ноутбук не зупиниться, а одразу перейде до apt.

## Що робиться в ноутбуці

1. **Завантаження даних.** Створюємо схему `pandemic`, робимо її схемою за
   замовчуванням (`SET search_path`) і імпортуємо CSV у таблицю
   `infectious_cases` через `COPY ... FROM STDIN`.
2. **Нормалізація до 3НФ.** `Code` залежить тільки від `Entity`, тому
   таблицю розділено на `entities` (унікальні пари Entity + Code) і
   `disease_stats` (показники по роках з `entity_id` замість тексту).
   Кількість рядків звірено з вихідною таблицею.
3. **Аналіз `Number_rabies`.** Для кожної комбінації Entity + Code —
   середнє, мінімум, максимум і сума; сортування за середнім за спаданням,
   топ-10.
4. **Різниця в роках вбудованими функціями.** `MAKE_DATE(year, 1, 1)`,
   `CURRENT_DATE` та `DATE_PART('year', AGE(...))`.
5. **Власні функції.** `years_diff(p_year)` — той самий розрахунок, що й у
   пункті 4 (результати звірено рядок у рядок), та
   `avg_cases_per_period(cases, divisor)` — середня кількість захворювань
   за період; перевірено з дільниками 12 (місяць), 4 (квартал), 2 (півріччя).

## Примітка

`CURRENT_DATE` залежить від дня запуску, тому значення різниці в роках
у виводі відповідають даті виконання ноутбука.
